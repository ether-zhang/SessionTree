# Support

SessionTree is maintained by [ether-zhang](https://github.com/ether-zhang).

For installation help, bugs, or feature requests, [open a GitHub issue](https://github.com/ether-zhang/SessionTree/issues/new). Include the plugin version, Codex client version, Windows version, steps to reproduce, and the expected and actual results.

Issues are public. Do not include conversation contents, account credentials, tokens, the contents of your Codex data directory, or unsanitized file paths. Prefer synthetic examples and redact screenshots before posting.

The supported package currently targets Codex desktop on Windows x64 and local conversations. The normal entry is **New tab → More tools → Session Tree** in the conversation's right-hand pane. Adding the MCP to the message composer is not the panel entry.

For a closed transport, first fully quit and reopen Codex, then reopen the panel. See the [installation and usage guide](README.md) for removing the package or restoring a development copy.

Support is provided through this repository without a guaranteed response time.

# Roadmap

- A shallower conversation-scoped entry when the host exposes an appropriate extension point.
- Confirmation of native panel visibility events so hidden tabs can pause refresh reliably.
- Additional operating systems and remote-host conversation support after validation.
- Hermes Desktop adapter and native SDK plugin on `feat/hermes-adapter`, sharing the tree core and renderer. Native desktop acceptance remains pending; SDK list coverage and archive limits are documented in [Hermes notes](HERMES.md).
- Additional agent adapters while retaining the generic tree/index and shared presentation layers.

The current conversation entry is **New tab → More tools → Session Tree**. This release does not add a title-bar button or modify Codex client files.

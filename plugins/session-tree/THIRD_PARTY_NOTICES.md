# Third-party runtime

This package includes the unmodified official Node.js 24.22.0 Windows x64 executable.

Source: https://nodejs.org/download/release/v24.22.0/node-v24.22.0-win-x64.zip

Official checksums: https://nodejs.org/download/release/v24.22.0/SHASUMS256.txt

The complete upstream license, including notices for dependencies compiled into Node.js, is included in [runtime/LICENSE](runtime/LICENSE). The runtime license does not assign a license to SessionTree.

The plugin starts this executable directly; it does not install Node.js globally, use npm, or download code on first use.
